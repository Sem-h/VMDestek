  Proje Hakkında
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  VMDestek, web siteleri için geliştirilmiş açık kaynaklı bir 
  canlı destek (live chat) sistemidir. Ziyaretçilerinizle 
  gerçek zamanlı olarak iletişim kurmanızı sağlar.

  Özellikler:
  ─────────────────────────────────────────────────────────────
  • Gerçek zamanlı canlı sohbet
  • Birden fazla müşteri temsilci desteği
  • Ziyaretçi bilgileri takibi (IP, tarayıcı, sayfa)
  • Konuşma notları ve hatırlatmalar
  • Hazır yanıt şablonları
  • Otomatik yanıt sistemi
  • Çalışma saatleri ayarları
  • Sohbet değerlendirme (yıldız puanlama)
  • Widget renk ve tema özelleştirme
  • Baloncuk (bubble) modu ile minimal tasarım
  • Karşılama mesajı ve tooltip
  • Mobil uyumlu (responsive) arayüz
  • Kolay embed kodu ile entegrasyon
  • Admin paneli ile tam kontrol
  • Kullanıcı yönetimi (Admin/Operatör rolleri)

  Sistem Gereksinimleri
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  • PHP 7.4 veya üzeri
  • MySQL 5.7+ veya MariaDB 10.3+
  • Apache / Nginx web sunucusu
  • PDO PHP eklentisi
  • mbstring PHP eklentisi

  Kurulum
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Dosyaları web sunucunuza yükleyin
  2. Tarayıcınızda install.php dosyasını açın:
     http://siteadresiniz.com/install.php
  3. Kurulum sihirbazını takip edin:
     - Veritabanı bilgilerinizi girin
     - Admin hesabı oluşturun
     - Kurulumu tamamlayın
  4. Admin paneline giriş yapın:
     http://siteadresiniz.com/admin/
